# skills

Claude Code skills. Everything in `.claude/skills/` loads automatically in any Claude Code session that has this repository open.

## Source

The skills in `.claude/skills/` are copied from [affaan-m/ECC](https://github.com/affaan-m/ECC) (v2.2.3, commit d4b97e6) under the MIT licence. The licence is in `.claude/skills/ECC-LICENSE`. ECC's hooks, agents and commands are not included.

To remove a skill, delete its folder.
